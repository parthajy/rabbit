## Priority 2: Compile on Ingest (Week 3)

*From Karpathy's insight: synthesize knowledge when data arrives, not when user asks.*

### What Changes

**Before:** Memory arrives → store raw → synthesize at query time (slow)

**After:** Memory arrives → store raw → Rabbit ALSO updates pre-built entity/topic pages (fast reads later)

### Entity Pages (auto-maintained)

Every person, org, project, and topic gets a living page:

```
ENTITY: Acme Corp
Type: Organization
Last updated: April 6, 2026

Summary: Enterprise client in Q2 renewal. Primary contact Tom. 
Contract value $45K. They want quarterly billing (decision pending).
Last meeting April 3 — discussed renewal timeline.

Key People: Tom (primary), Sarah (procurement)
Open Items: Quarterly billing decision, contract signing
Recent Activity:
  - Apr 3: Renewal discussion meeting
  - Mar 28: Budget approved at $45K
  - Mar 15: Initial outreach from Tom

Related: [Pricing Strategy], [Q2 Revenue Targets], [Enterprise Clients]
```

### Implementation

```
Memory arrives (email about Acme)
  → [EXTRACT] → entities: Acme, Tom, $45K
  → [SUMMARIZE] → summary of this specific memory
  → For each entity found:
      → Fetch existing entity page
      → [ANSWER] "Update this entity summary with new information: [new memory]"
      → Save updated entity page
  → [LINK] → connect to related memories
```

### API

```
POST /v1/ingest → processes + updates entity pages
GET  /v1/entity/{name} → returns pre-built entity page (instant)
GET  /v1/topic/{name} → returns pre-built topic page (instant)
```

### Impact
- 90% of queries become instant reads (10ms vs 3-5 seconds)
- Entity pages always current
- No RAG latency for common questions

## Priority 3: Answers Become Knowledge (Week 3-4)

*Every great synthesis Rabbit creates gets saved as reusable knowledge.*

### What Changes

**Before:** User asks question → Rabbit synthesizes → answer shown → forgotten

**After:** User asks question → Rabbit synthesizes → answer shown → saved as compiled knowledge → next person gets instant answer

### Implementation

```
User asks: "What's our pricing strategy?"
  → Rabbit generates conversational answer with citations
  → Answer shown to user
  → IF answer quality score > 0.8:
      → Save as compiled memory:
        Title: "Pricing Strategy — Current State"
        Content: the synthesized answer
        Type: "compiled_knowledge"
        Sources: [linked to original memories]
        Auto-update: when source memories change, re-synthesize
  → Next person asks similar question:
      → Embedding match finds compiled knowledge
      → Instant answer, no re-synthesis needed
```

### Staleness Detection

```
Compiled knowledge has source links.
When a source memory gets updated or contradicted:
  → Mark compiled knowledge as "stale"
  → Re-synthesize on next access or in lint pass
```

### Impact
- Knowledge compounds with every interaction
- Frequently asked questions get instant answers
- Organization builds a self-authored knowledge base

## Priority 4: Lint Pass — Self-Healing Knowledge Base (Week 4-5)

*Daily background job where Rabbit audits the entire knowledge base.*

### What It Checks

```
RABBIT LINT — Runs daily at 2:00 AM

1. CONTRADICTIONS
   → Compare entity pages with recent memories
   → [AMBIENT] signal detects conflicts
   → Auto-flag or auto-resolve

2. STALE INFORMATION
   → Find dates that have passed with no follow-up
   → "Launch date: March 30" — did it happen?
   → Flag for human review

3. MISSING LINKS
   → Find memories mentioning entities with no entity page
   → Auto-create entity pages
   → Find memories that should be linked but aren't

4. ORPHAN MEMORIES
   → Memories with zero links to any entity/topic
   → Attempt to link or archive as noise

5. KNOWLEDGE GAPS
   → Projects with planning memories but no progress updates
   → People mentioned frequently with thin entity pages
   → Topics discussed but never resolved

6. COMPILED KNOWLEDGE FRESHNESS
   → Check if source memories have changed
   → Re-synthesize stale compiled knowledge
```

### Output

```
Daily lint report → sent to workspace admin
  - X contradictions found (Y auto-resolved)
  - X stale items flagged
  - X new entity pages created
  - X orphan memories archived
  - X knowledge gaps identified
  - X compiled answers refreshed
```

### Implementation

```
Cron job: 2:00 AM daily
  → Load all entity pages
  → For each: [AMBIENT] check against recent memories
  → Load all unlinked memories
  → For each: [LINK] attempt to connect
  → Load all compiled knowledge
  → For each: check source freshness
  → Generate lint report
  → Send notification to workspace admin
```

### Impact
- Knowledge base is always clean and current
- Contradictions caught before they cause problems
- Zero human maintenance effort
- Enterprise differentiator: "self-maintaining knowledge base"

## Priority 5: Additional Open-Source Models (Week 5-6)

### 5.1 Jina Reranker (HIGH IMPACT)
- 137M params, fits on T4 alongside everything
- Reranks search results for relevance
- Improves answer quality by feeding Rabbit better context
- Implementation: embed search → top 20 → reranker → top 5 → Rabbit ANSWER

### 5.2 Cohere Transcribe (already planned)
- 2B params, Apache 2.0
- Replaces AssemblyAI
- On-prem audio transcription
- One less external dependency

### 5.3 ColPali — Visual Document Understanding (DIFFERENTIATOR)
- 3B params, MIT license
- "Sees" PDFs, slides, charts, images

- Demo moment for enterprise sales
